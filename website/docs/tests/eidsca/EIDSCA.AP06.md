## Overview

Controls whether users can join the tenant by email validation. To join, the user must have an email address in a domain which matches one of the verified domains in the tenant.

[Self-service sign up for email-verified users - Microsoft Entra ID - Microsoft Learn](https://learn.microsoft.com/azure/active-directory/enterprise-users/directory-self-service-signup)

#### Test script

https://graph.microsoft.com/beta/policies/authorizationPolicy
