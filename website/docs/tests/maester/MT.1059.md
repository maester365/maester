## Overview

Microsoft Defender for Identity health issues should be resolved.

Maester reads the Defender for Identity health issues of the tenant and creates one result per issue (MT.1059.&lt;hash of the issue name&gt;). The severity of each result is the severity Defender for Identity reports for the issue. Issues whose alerts have all been suppressed or dismissed are skipped.

#### Remediation action

Follow the recommendations of each open health issue in the Microsoft Defender portal.
