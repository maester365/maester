## SYNOPSIS

Returns what a Maester Pack connector kept with Set-MtConnectionState, or nothing when it is not connected.

## SYNTAX

```powershell
Get-MtConnectionState [[-Service] <String>] [-Detailed] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

A pack's tests and helpers call this to reach the service their connector connected to (Maester Packs
design, section 6.1).
Inside a pack, it returns the state of the pack's own connector, or of a pack it
requires; one pack cannot read another pack's connection.
Called from outside a pack, -Service is
required.

By default the value the connector kept is returned.
-Detailed returns Service, Value, Account, Tenant
and ConnectedAt.

## EXAMPLES

### EXAMPLE 1

```powershell
$token = (Get-MtConnectionState).Token
```

Inside a pack test: the token the pack's connector kept.

### EXAMPLE 2

```powershell
Get-MtConnectionState -Service CNT.GoogleWorkspace -Detailed
```

At the console: who is connected to the service of an installed pack.
