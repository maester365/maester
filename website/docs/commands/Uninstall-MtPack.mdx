## SYNOPSIS

Removes a Maester Pack from maester-packs.lock.json and the Maester config.

## SYNTAX

```powershell
Uninstall-MtPack [-Id] <String[]> [-PackLock <String>] [-ProgressAction <ActionPreference>] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

The pack and the modules only it needed are removed from the lock file, and its entry from the Packs
list of maester-config.json, so Invoke-Maester no longer runs it.
A pack that another installed pack
requires is not removed.
The files stay in the local pack store, which other projects may share.

A pack that ships with Maester cannot be uninstalled; turn it off in the config instead, with
Packs: [\{ "Id": "maester.zero-trust-assessment", "Enabled": false \}].

## EXAMPLES

### EXAMPLE 1

```powershell
Uninstall-MtPack contoso.google-workspace
```

Removes the pack from the project.
