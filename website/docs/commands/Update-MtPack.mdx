## SYNOPSIS

Updates installed Maester Packs to their newest release that has met the cooldown, showing what changed.

## SYNTAX

```powershell
Update-MtPack [[-Id] <String[]>] [-Version <String>] [-PackLock <String>] [-AcceptRisk <String>]
 [-IncludeRecent] [-NonInteractive] [-Force] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION

Each pack is installed again from its source with the same checks as Install-MtPack: the cooldown, the
pack policy, the blocklist and the scan.
The approval shows what changed since the version you
approved: new services, scopes, network hosts, modules and a higher risk.
A pack whose newest release
has the files you approved is left as it is, without asking again, and reported as UpToDate.

## EXAMPLES

### EXAMPLE 1

```powershell
Update-MtPack
```

Updates every pack installed from GitHub.

### EXAMPLE 2

```powershell
Update-MtPack contoso.google-workspace -Version 1.3.0
```

Updates one pack to a given release.
