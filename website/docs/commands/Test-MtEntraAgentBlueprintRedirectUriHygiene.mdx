## SYNOPSIS

Finds Agent Identity Blueprints with wildcard or plain-http redirect URIs.

## SYNTAX

```powershell
Test-MtEntraAgentBlueprintRedirectUriHygiene [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Checks whether any Agent Identity Blueprint's web redirect URIs contain a wildcard or use
plain HTTP instead of HTTPS (excluding loopback addresses).
A wildcard redirect URI lets a
token be redirected to any attacker-controlled host that matches the pattern.
A plain-http,
non-loopback redirect URI returns tokens over an unencrypted channel.
