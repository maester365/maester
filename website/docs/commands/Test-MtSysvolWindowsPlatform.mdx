## SYNOPSIS

Determines whether the SYSVOL Windows adapter should be used.

## SYNTAX

```powershell
Test-MtSysvolWindowsPlatform [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Returns true on Windows PowerShell and PowerShell running on Windows.
This
helper isolates platform detection so the public transport contract does
not expose platform-specific switches.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-MtSysvolWindowsPlatform
```
