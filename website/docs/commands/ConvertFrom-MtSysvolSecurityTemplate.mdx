## SYNOPSIS

Parses relevant sections of a GptTmpl.inf security template.

## SYNTAX

```powershell
ConvertFrom-MtSysvolSecurityTemplate [-Content] <String> [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Returns ordered Registry Values and Privilege Rights dictionaries.
Other
INF sections are deliberately ignored because they are not required by the
GPO state checks.

## EXAMPLES

### EXAMPLE 1

```powershell
ConvertFrom-MtSysvolSecurityTemplate -Content "[Privilege Rights]`nSeDebugPrivilege=*S-1-5-32-544"
```
