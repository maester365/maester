## SYNOPSIS

Lists Maester native tests and their metadata without connecting to a tenant.

## SYNTAX

```powershell
Get-MtTest [[-Id] <String[]>] [-Tag <String[]>] [-Path <String>] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Without -Path, returns the tests that ship with Maester (the catalog).
With -Path, reads the native
tests (Test.&lt;ID&gt;.ps1) in a file or folder and validates them; each object's Errors property lists
every problem with its line, and IsValid is $false when there is one.
No test code is run.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-MtTest -Tag CA | Format-Table Id, Title, Severity
```

Lists the built-in Conditional Access tests.

### EXAMPLE 2

```powershell
Get-MtTest -Path ./Custom | Where-Object { -not $_.IsValid } | Select-Object -ExpandProperty Errors
```

Shows every problem in the custom tests.
