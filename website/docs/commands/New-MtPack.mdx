## SYNOPSIS

Creates a new Maester Pack folder: maester-pack.json, a suite with a first test, and optionally a connector.

## SYNTAX

```powershell
New-MtPack [-Path] <String> -Id <String> -Code <String> [-Name <String>] [-Connector]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

A pack is a folder, usually a GitHub repository, that others install with Install-MtPack.
This
writes its manifest, a README, a tests folder with suite.json and a first test MP.&lt;Code&gt;.1001, and with
-Connector a connector for a service of your own and a helper that reads its connection.

Check it with Test-MtPack, and run its tests with Invoke-MtTest -Path.
Publish it by pushing the folder
to GitHub under the publisher's account and creating a release.

## EXAMPLES

### EXAMPLE 1

```powershell
New-MtPack -Path ./maester-google-workspace -Id contoso.google-workspace -Code CNT -Connector
```

Creates a pack with a connector for the service CNT.GoogleWorkspace.

### -Code

The pack's code, which starts every test ID of the pack: CONTOSO for MP.CONTOSO.1001.
Two to ten letters or
digits, starting with a letter.
A publisher with several packs can group them with up to three parts
separated by dots, such as CNT.GWS for MP.CNT.GWS.1001.
No two installed packs may share a code, or have
one code that starts with the other.
