## SYNOPSIS

Checks for dynamic groups that use the retiring memberOf rule operator.

## SYNTAX

```powershell
Test-MtDynamicGroupMemberOfRule [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Finds user and device dynamic membership rules that use memberOf.
Microsoft ends the public
preview on November 3, 2026, after which affected groups stop updating and retain membership.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-MtDynamicGroupMemberOfRule
```
