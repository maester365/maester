## SYNOPSIS

Parses Group Policy Preferences XML for password findings.

## SYNTAX

```powershell
ConvertFrom-MtSysvolGppXml [-Content] <String> [-RelativePath] <String> [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Loads XML with DTD processing prohibited, finds cpassword attributes at any
depth, and detects common weak plaintext defaults only in password-named
XML attributes or elements.
Password values are never returned.

## EXAMPLES

### EXAMPLE 1

```powershell
<User cpassword="x" /></Groups>' -RelativePath 'Groups.xml'
```
