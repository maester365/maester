`Connect-Maester` connects to Microsoft Graph. That is enough for the Entra ID tests and most of the others. The Exchange Online, Teams and SharePoint tests need their own PowerShell modules, and SharePoint also needs an app registration whose client ID you pass with `-SharePointClientId`. [Installation](http://localhost:3278/docs/installation#optional-modules-and-permissions) covers both. Then connect to all the services:

```
Connect-Maester -Service All -SharePointClientId '<Client ID>'
```

`Invoke-Maester`
Tests for a service you have not connected to are reported as Skipped, with the reason, so you can tell which results are missing and why. See [Connect-Maester](http://localhost:3278/docs/connect-maester).
