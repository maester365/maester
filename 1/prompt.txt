Background (from the session that started this one):
Maester is a PowerShell framework that checks Microsoft 365 security configuration. The defender's path (design accepted 5 November 2026, docs/proposals/defenders-path.md) orders fixes the way Microsoft Learn documents: what must be in place first, what a fix unlocks, and whether the tenant is ready.
