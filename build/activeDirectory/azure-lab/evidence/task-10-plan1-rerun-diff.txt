LAB CHANGES THAT ENABLE THE DEFINITIVE RESULTS
1. Certificates: every DC has a Server Authentication certificate with short-name,
   FQDN, and domain SANs; its trust anchor is installed on both runners. This enables
   trusted LDAPS/636 and StartTLS/389 while preserving hostname validation.
2. DNS: DC02 is the canonical runner/VNet resolver, the child delegation resolves
   child.misoule02.local, and reciprocal conditional forwarders resolve
   misoule03.local without creating an authentication trust.
3. Runner identity: MiSouleRunnerWin/MSRunnerWin is domain-joined to
   misoule02.local; MiSouleRunnerLinux is enrolled through realmd/SSSD. Separate-
   forest success rows still require explicit MISOULE03 credentials.

PROCESS ENFORCEMENT ADDED BY PLAN 9
1. Test-LabPrerequisites.ps1 is a binary first gate. It checks VM state, DNS from
   both runners, RootDSE identity, banned-module absence, LDAPS trust/hostname,
   StartTLS handshake, runner auth state, and the intended trust model.
2. If any mandatory preflight check fails, no probe or public E2E row starts. The
   scenario is recorded as BLOCKED_BY_PREFLIGHT with failed CheckIds; it is never
   counted as validated.
3. Invoke-ProtocolProbeMatrix.ps1 must produce all 16 positive and negative rows,
   including bind outcome, requested/resolved identity, auth mode, and TLS mode.
4. Invoke-PublicE2EMatrix.ps1 must produce all 15 rows in isolated processes. Each
   successful row must use Connect-Maester/Connect-MtAdTarget, execute AD tests,
   and produce JSON, Markdown, and HTML reports.
5. Existing evidence cannot waive a row. Rerun-Plan1-Under-Plan9.ps1 uses fresh
   timestamped directories, checks exact row IDs, preserves all artifacts, and
   treats missing/mismatched rows as process failures.
