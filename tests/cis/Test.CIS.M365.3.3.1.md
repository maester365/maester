At least one sensitivity label policy is published, so users can apply sensitivity labels to their files and email.

Sensitivity labels classify content and can add encryption, markings and access restrictions that stay with a file when it leaves your tenant. A label that is not published to users cannot be applied, so a tenant without a published policy has no consistent way to say which content is confidential.

Creating the labels is only the first step. A label policy makes them available to the users and groups that you choose, and can set a default label and require users to label content.

#### Remediation action

1. Sign in to the [Microsoft Purview portal](https://purview.microsoft.com).
2. Go to **Solutions** > **Information Protection** > **Sensitivity labels** and create the labels you need.
3. Open the [**Label policies**](https://purview.microsoft.com/informationprotection/labelpolicies) tab and select **Publish label**.
4. Choose the labels, the users and groups to publish to, and the policy settings, such as a default label and mandatory labelling.
5. Finish the wizard.
